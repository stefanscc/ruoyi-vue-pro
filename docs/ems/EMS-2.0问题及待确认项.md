

# EMS-2.0问题及待确认项

## 1. 前置机与EMS通信协议

- **通信协议**： 建议采用MQTT协议

- **消息体序列化协议**： 建议采用Protobuf

- **YC、YX Topic**：
  `遥测：/sys/{gcpNo}/{gwNo}/{pk}/{dn}/yc/post`
  `遥信：/sys/{gcpNo}/{gwNo}/{pk}/{dn}/yx/post`
  
	`gcp`：Grid Connection Point（并网点）
	
	`gw`：Gateway（网关）
	
	`pk`：ProductKey（产品标识）
	
	`dn`：Device Number（设备编号）
	
- **YT、YK Topic**: 

  `ems下行`：/ems/sys/{gcpNo}/{gwNo}/control

  `前置机上行`: /ems/sys/{gcpNo}/{gwNo}/control_reply
